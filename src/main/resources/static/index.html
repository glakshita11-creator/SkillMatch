Common Inquiries

Frequently Asked Questions

Everything you need to know about navigating the SkillMatch campus portal.

How does automated criteria checking work? +
When an employer publishes an opening, they specify minimum CGPA requirements, eligible degree departments, and eligible graduation batch years. When a student clicks Apply, SkillMatch validates these rules in the backend. If criteria are unmet, the system clearly explains which requirement wasn't satisfied.
What security measures are applied to uploaded resumes? +
Resumes are stored on hardened server storage using unique GUID-hashed filenames. During upload, the server verifies both the extension and the binary %PDF magic bytes to prevent spoofing. Files are protected by Spring Security so that only the student, recruiters reviewing that specific application, and administrators can stream the PDF.
Can students withdraw a submitted application? +
Yes. Prior to a final placement outcome (Selected or Rejected), students can withdraw their application directly from their applications dashboard. Once withdrawn, the recruiter's candidate roster immediately updates.
How do recruiters schedule interviews? +
Corporate recruiters have an intuitive workflow modal in their applicant pipeline where they can update applicant status to "Interview Scheduled", set the exact interview date and time, and include instructions or meeting links. The student sees this instantly on their visual journey stepper.
Can company recruiters see applicants from other companies? +
No. SkillMatch enforces strict corporate isolation. Recruiter accounts can only access opportunities published by their own verified organization and can only evaluate candidates who submitted applications to their roles.
